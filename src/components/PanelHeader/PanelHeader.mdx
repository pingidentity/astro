# PanelHeader

The PanelHeader component allows for easy creation of header items within a panel. It comes with pre-defined styles that match Ping specs. You can utilize the `data` prop to pass in text, subtext, image and an mdi or svg icon.

### Recommended Use
This component is intended to be used as a header within a panel.

#### Icons and Images
Add an icon by passing an mdi or svg icon to the `data.icon` prop. Under the Onyx theme, the icon renders inside an Avatar. Under the legacy Astro theme, the icon renders on its own.

Add an image by passing an object with a `src` key to the `data.image` prop. `alt` and `aria-label` keys are supported but not required.

If both an icon and an image are provided the icon will be rendered.

#### Avatar Colors and Avatars (Onyx theme)
Under the Onyx theme, the icon avatar's color is resolved from the `colorId` prop:

- If `colorId` exactly matches a two-tone color name (`orange`, `cyan`, `green`, `purple`, `pink`, `red`, `yellow`, `teal`, `blue`, `indigo`, `lightBlue`, `lightPink`, `lightGreen`, `lightYellow`, `lightIndigo`), the avatar renders directly in that color. Substring matches do not apply: `user-cyan` is treated as an arbitrary id.
- Any other `colorId` value is used as the seed for deterministic color interpolation.
- When `colorId` is not provided, `data.avatarDefaultText` seeds the interpolation.
- When neither `colorId` nor `data.avatarDefaultText` is provided, `avatarInitials` seeds the interpolation deterministically from its value.
- When none of these is provided, the avatar renders its default color (green).

The icon avatar renders square by default. Pass `isIconRound` to render it round instead.

Pass `avatarInitials` to render initials inside the avatar instead of the icon. Initials also render when no icon is provided. When no icon and no image are provided, an avatar renders using `data.avatarDefaultText` (also the color seed), and it is square.

Use `avatarProps` to pass props through to the underlying Avatar (for example `color` to force a specific color, or `sx` for one-off styling). `children` is managed by the component and should not be passed through `avatarProps`.
